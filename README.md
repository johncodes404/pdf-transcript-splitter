# 成绩单 PDF 拆分工具

把一个总 PDF 按姓名拆成独立成绩单 PDF。适合“前面是目录，后面通常每人 2 页，少数人为 3/4 页”的场景。

## 使用方式

1. 已有打包程序时，双击 `成绩单PDF拆分工具.exe`。从源码运行时，先安装 Python，再双击 `run_windows.bat`（首次运行会联网安装 `pypdf`）。
2. 点击“选择文件”，或者把一个 PDF 从资源管理器拖进工具窗口。拖入时窗口边缘会变蓝；工具会读取总页数，但不会自动拆分。
3. 如有需要，填写文件名前缀，例如 `2026秋季-`，最终文件名会是 `2026秋季-张三.pdf`。前缀可留空。
4. 点击左侧“输入姓名”框，输入或粘贴姓名，一行一个，顺序必须与 PDF 中成绩单顺序一致。空白时显示输入提示，获得焦点后边框变蓝；有姓名后显示序号和隔行底色。支持全选、撤销，提示文字不会计入姓名。
5. 默认“目录 1 页、每人 2 页”，点击“生成方案”。左右分隔线可拖动，窗口放大后可查看更多行。
6. 在右侧检查方案。如果总页数不吻合，双击特殊人员的“页数”修改，回车或移开焦点提交，Esc 取消；也可选中人员后快速设为 2/3/4 页。特殊页数加粗显示。
7. 只有当全部页数恰好覆盖时，“开始拆分”按钮才会启用。
8. 输出默认放在原 PDF 旁边的 `原文件名_拆分结果` 文件夹中。
9. 成功后底部显示生成数量，点击“打开结果文件夹”查看。名单或基础规则修改后，必须重新生成方案。

## 设计原则

- 默认值优先：绝大多数人无需操作，只处理例外。
- 前缀只影响输出文件名，不影响拆分方案；修改前缀后无需重新生成方案。
- 强制完整性校验：页数不吻合时禁止拆分，避免从某个人开始整体错位。
- 不覆盖旧结果：若结果目录已存在，会自动创建 `_2`、`_3` 等新目录。
- 原 PDF 永远不修改。
- 重复姓名会阻止拆分，避免输出文件相互覆盖。

## 打包成 Windows EXE

在安装了 Python 的 Windows 电脑上，打开本工具目录，双击以下文件。首次打包需要联网安装依赖：

```text
build_windows.bat
```

等待黑色窗口出现 `Build complete` 或“打包完成”，然后按任意键关闭窗口。生成的程序位于：

```text
dist\成绩单PDF拆分工具.exe
```

之后使用者只需要这个 EXE，不需要安装 Python 或依赖。打包脚本会自动使用 `app.ico` 作为 EXE 和程序窗口图标，并通过 `hook-tkinterdnd2.py` 收集拖放功能需要的原生组件。

更新源码后需要重新打包，已有 EXE 不会自动更新。删除旧 EXE、`dist` 或 `build` 文件夹后，也可以用同一个脚本重新生成；请保留源码、`requirements.txt`、`app.ico` 和打包脚本。

仓库的 `.gitignore` 已忽略 Python/pytest 缓存、本工具的 `build/`、`dist/` 和自动生成的 `成绩单PDF拆分工具.spec`。这些文件保留在本机，不提交到 Git；打包脚本和源码仍正常跟踪。

如果日志停止滚动且窗口标题出现“选择”，按 `Esc` 退出文本选择模式，再等待打包继续。

## 三个启动文件的区别

| 文件 | 用途 | 窗口表现 |
| --- | --- | --- |
| `run_windows.bat` | 直接运行源码、体验修改后的界面 | 工具界面和黑色命令行窗口同时出现，属于正常情况 |
| `build_windows.bat` | 打包生成独立 EXE | 黑色窗口显示打包日志 |
| `dist\成绩单PDF拆分工具.exe` | 日常使用、复制给其他电脑 | 只显示工具界面 |

从源码启动时，使用期间保留黑色窗口；关闭黑色窗口可能同时结束程序。

## 在新电脑使用

1. 在打包电脑上找到最新生成的 `dist\成绩单PDF拆分工具.exe`。
2. 通过 U 盘、网盘等方式将这个 EXE 复制到新电脑。
3. 新电脑需运行与打包产物兼容的 Windows 系统。当前使用 Windows 64 位环境打包，目标电脑也应为兼容的 Windows 64 位系统；该 EXE 不能直接用于 macOS 或 Linux。
4. 双击 EXE，选择需要拆分的 PDF，按上面的使用步骤操作。

新电脑无需安装 Python，无需复制源码、`build` 文件夹或 `.bat` 脚本，运行时也无需联网。PDF 需要能在新电脑上访问，其所在文件夹需要允许写入；结果保存在该 PDF 旁的 `原文件名_拆分结果` 文件夹，已有同名结果时自动追加编号，不覆盖旧结果。

## 开发验证

在工具目录执行 `python -m pip install pytest`，然后执行 `python -m pytest test_core.py test_ui.py -q`。界面测试需要有桌面会话，会短暂打开测试窗口；测试 PDF 和拆分结果写入临时目录，不使用真实成绩单。

## 文件说明

- `app.py`：GUI 界面。
- `app.ico`：应用图标（已针对桌面图标尺寸压缩）。
- `core.py`：PDF 页数校验、拆分与文件名处理。
- `requirements.txt`：运行依赖。
- `hook-tkinterdnd2.py`：打包拖放功能所需组件的 PyInstaller 钩子。
- `run_windows.bat`：Windows 快速启动。
- `build_windows.bat`：打包独立 EXE。

## 当前边界

- 不做 OCR，也不自动识别姓名；姓名由使用者粘贴，减少识别错误。
- 暂不支持需要密码才能打开的 PDF。
- 目录页数可调整，不要求固定为 1 页。
